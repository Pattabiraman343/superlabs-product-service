# SuperLabs Product Service

## Tech Stack
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- React + Vite
- Swagger
- Render
- Vercel

## Features
- Product CRUD
- Product Search
- Pagination
- Product Detail API
- Admin Panel
- Swagger API Docs
